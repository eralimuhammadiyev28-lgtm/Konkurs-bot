## 2-QADAM: Botni kanalga admin qilish

1. Telegram kanalingizga boring
2. Kanal sozlamalari → Adminlar → Admin qo'shish
3. Botingizni qidiring va admin qiling
4. Faqat "A'zolarni ko'rish" huquqi yetarli

## 3-QADAM: Railway.app ga yuklash (BEPUL)

### 3.1 — GitHub ga yuklash
1. github.com ga boring va ro'yxatdan o'ting (bepul)
2. "New repository" tugmasini bosing
3. Nom bering (masalan: konkurs-bot)
4. "Create repository" bosing
5. Barcha fayllarni yuklang (Upload files)

### 3.2 — Railway ga ulash
1. railway.app ga boring
2. "Start a New Project" bosing
3. GitHub bilan kirish (Sign in with GitHub)
4. "Deploy from GitHub repo" tanlang
5. Yaratgan repositoryingizni tanlang
6. "Deploy Now" bosing

### 3.3 — Bot tayyor!
Railway avtomatik o'rnatadi va ishga tushiradi.
5-10 daqiqadan keyin bot ishlaydi.
